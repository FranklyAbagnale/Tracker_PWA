# 09 Testing

Test plan, manual checklist, tester guide, first steps, phone testing with sample data, and known failure modes. Automated tests are described in `../tests/README.md`.

The screenshot walkthrough of the app is `../web/tutorial.html` (a single file; open it in a browser or from **Tutorial** in the app's menu). It shows the app with the location switch, live plate results, Share and Navigate. Screenshots use sample data and the placeholder name "Melting Codename". The abbreviation list is `../web/glossary.html` (menu: **Glossary**); its state list is generated from `web/js/config.js`, so it stays current when states are added.
