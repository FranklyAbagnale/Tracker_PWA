Tracker data tool

Search, review and fix the data in your local clone

Open the folder where you cloned the ParkingTracker repo (the one that contains data/ and photos/). Everything runs in this page: it makes no network requests, and it only touches the folder you pick.

  • New since last review: records that appeared (or got new sightings) since you last pressed Mark all reviewed.
  • Filter any field: type words (make:ford -cleared "roof rack") and tick values in the lists on the left.
  • Edit: click a record to fix its details, plates and sightings, or change many at once. Nothing is written until you press Save to disk.
  • Saving updates data/index.json too, so after git push no workflow has to run.

Search text

Words are ANDed. "two words", -exclude, field:value (name, color, make, model, year, body, flag, plate, state, notes, features, observer, source, by, key).
