Import

Adds records to ParkingTracker from a legacy plate-tracker XML export or from a spreadsheet saved as CSV, and gives you a ZIP to unpack in the repository. Everything runs in this page; your files are not uploaded anywhere (except address lookups, if you ask for them).

1. What are you importing?

Choose the file in the box that matches it (or drop it below). The page switches to the right steps for XML or CSV by itself. One kind of file at a time.

Drop an XML or CSV file here, or choose below

    In Excel or Numbers use Save As / Export → CSV. Not sure about the layout? Download a template CSV (two made-up example rows; replace them with yours).

    Which columns can the CSV have?

    Column names are matched automatically and you can change any of them in step 3. Only a plate or a vehicle description plus a date is really needed; everything else is optional.

    Column (examples of headings)Becomes
    License Plate, PlateThe plate number. Spaces and dashes are ignored. Blank, NONE or NO PLATE means the sighting has no plate.
    StatePlate state: CA, California, Calif. all work. Anything not understood becomes XX (unknown) and is kept in the notes.
    Color, Make, ModelThe vehicle. A single Vehicle column such as Silver Ford Expedition also works.
    Type, Body Stylesedan, SUV, truck, van (minivan too), coupe or hatchback. If blank, it is guessed from the model (an Expedition is an SUV); otherwise unknown.
    Earliest Seen, Last SeenOne sighting at each date (one sighting if both dates are the same). Or use a single Date column for one sighting per row.
    AddressLooked up on the map (step 4). A city name alone is not an address: it goes to the notes.
    Latitude, LongitudeExact map location, if you have it.
    Flagunknown, suspected, confirmed, cleared or pigs. Blank uses the flag chosen in step 4.
    YearModel year (1900 to 2100).
    Notes, CommentsThe sighting's notes.
    Anything else (City…)Added to the notes as City: value, so nothing is lost.

    2. Your existing data (important)

    Choose the data folder inside your copy of the repository. The tool compares every record or row with what is already there, skips the ones already imported, joins new sightings to a vehicle that already has the plate, and adds only what is new. If you skip this step the tool cannot tell old records from new ones. Choose it even for a file you think is new: if it is already imported, you will be told.

    Push to the repository

    1. Unzip into the repository folder. The ZIP contains data/ and, if media was imported, photos/; they merge with what is there.
    3. Review, then commit and push: 
      git add data photos
git commit -m "Import records"
git push

    Keep the source files and the report out of the repository: they contain street addresses. Make the repository private before pushing real data.
