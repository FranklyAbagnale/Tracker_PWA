Tracker record editor

Pull up any level of the data and change what is in it

Open the folder where you cloned the ParkingTracker repo (the one that contains data/ and photos/). Everything runs in this page: it makes no network requests, and it only touches the folder you pick.

  • Four levels: Vehicles, Sightings (every sighting of every vehicle), Plates and Photos. Each has the same search, filters and selection.
  • Change: remove records, sightings, plates or photos; clear a location or notes; set a flag, observer, source, plate type or state in bulk. Click a row to edit one record by field or as raw JSON.
  • Staged, not written: every change waits in the bar at the bottom. Review & save shows exactly which files change, makes a backup ZIP of the originals, and only then writes. Discard all drops everything.
  • Saving rewrites data/index.json, so after git push no workflow has to run. Removed records stay in git history.
